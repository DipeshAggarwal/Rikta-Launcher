# Rikta Launcher
Rikta Launcher is an active fork of [Escape Launcher](https://github.com/GeorgeClensy/Escape-Launcher/).

Rikta means null in Sanskrit, and this is my guiding philsophy for the launcher.

## Note for Users
I am currently putting Rikta Launcher through a major refactoring phase.
During this transition, the app will become less and less identical to the original project and may be unstable, even if
it runs.

If you need a stable, production-ready minimalist launcher right now, I recommend using [Escape Launcher](https://github.com/GeorgeClensy/Escape-Launcher/).

## My Vision for Rikta Launcher
While I am starting from the Escape foundation, my goal is to completely transform the project.
By the end of the refactoring process, Rikta will be a distinct launcher with rewritten core logic and no compatibility 
with the original Escape Launcher.

I am building Rikta Launcher to support advanced focus-driven features, including:
* **App Renaming**: Complete control over your app list labels.
* **Multiple Profiles**: Separate environments for Work, Home, or Focus modes.
* **Context-Aware Profiles**
* **Usage Limits**: Hard boundaries to help you manage digital addiction.
* **Custom Backups**: A dedicated system for saving and restoring your unique configurations.
* **Visual Discouragement System**

## Current Features (Inherited from Escape)
* Minimalist, text-based home screen.
* Full support for Android 15's Private Space.
* Built-in screen time tracking.
* App-open countdowns to discourage mindless scrolling.
* Material You (Android 12+) color support.
