# Security Policy

## Supported Versions

Only the latest version of the launcher is officially supported. If you have any issues in a prior version, please 
upgrade to the latest version and check if the problem still persists.

If you are unable to update for some reason, you may open a GitHub Issue, and we will try our best to help. However, 
support for older versions cannot be guranateed.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it through the Security Tab on GitHub. Once reported, the issue 
will be reviwed and addressed as quickly as possible.
